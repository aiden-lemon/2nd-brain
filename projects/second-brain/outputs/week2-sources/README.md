## 수집 중 잡은 오류 3건

조사 결과가 초기 실측·지시를 정정했다. 자료 작성 시 정정본을 쓴다.

1. **`AGENTS.md`(597 B)는 컨텍스트에 로드되지 않는다.** `CLAUDE.md`가 import도 참조도 하지
   않는 모델 중립 포인터 문서다. 초기 집계 20,863 B → 정정 **21,293 B** (정정 2회 — 상세는 `00-internal-metrics.md` § 1). 더 중요한 것은
   **자동 로드 vs 지시로 읽는 것의 구분**이며, 후자는 compaction 후 사라진다.
2. **스킬 메타데이터 절감률은 셈법이 둘이다.** 프론트매터 블록 전체 8,508 B(4.5%) vs
   `name`·`description` 값만 6,823 B(3.6%). 셈법을 밝히고 하나만 쓴다.
3. **`ollama-local-models.md`는 MCP를 쓰지 않는다.** `grep -ci mcp` = 0. Ollama HTTP API
   직접 호출 절차서다. MCP 사례로 쓰면 틀리지만, **"붙였다고 다 MCP가 아니다"의 대비 소재로
   더 좋다** — MCP 쪽은 `google-workspace.md`(`uvx workspace-mcp`)다.
