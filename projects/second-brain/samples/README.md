# 변환 실습용 샘플 문서

문서 변환 스킬(`pdf2md-ingest` · `hwp2md-ingest` · `doc2md-ingest`)을 실습·검증할 때 쓰는
합성 문서 모음. 2주차 교육(`outputs/week2-context-mcp-skills.html`) 실습 자료다.

**전부 합성 데이터다.** 설비코드·부서·측정값·담당자는 모두 가상이며 실제 조직·인물·설비와
무관하다. 개인정보와 고객사 자료가 들어 있지 않으므로 커밋 가능하다.
(`VAULT_RULES.md` § Core Rules의 개인 실험 데이터 금지 조항에 걸리지 않는다.)

## 파일과 태우려는 경로

| 파일              | 포맷      | 담당 스킬           | 태우는 경로                | 실측 통계                                 |
| --------------- | ------- | --------------- | --------------------- | ------------------------------------- |
| `설비-점검-절차.docx` | OOXML   | `doc2md-ingest` | **D1** — pandoc 직행    | 헤딩 6 · 표 1(20셀) · 불릿 3 · 이미지 1 · 316자 |
| `점검-결과-보고.hwpx` | OWPML   | `hwp2md-ingest` | **H1** — 순수 Python 추출 | 표 1 · 403자 · 머리말 포함                   |
| `안전-교육-자료.pdf`  | 텍스트 PDF | `pdf2md-ingest` | **S2** — 텍스트 추출       | 1페이지 · 499자/페이지                       |
| `점검-기록지-스캔.pdf` | 이미지 PDF | `pdf2md-ingest` | **S4** — 비전 전사 제안     | 1페이지 · **0자** · 이미지 1                 |

각 샘플은 판정 분기를 실제로 태우도록 만들었다.

- **구조 보존 확인용** — `.docx`는 헤딩·표·불릿·임베디드 이미지를 모두 담고 있다. 변환
  결과에 `headings=6 tables=1 images=1`이 나오면 D1이 정상 동작한 것이고, `headings=0`이
  나오면 구조 손실 경로(D2b)를 탄 것이다.
- **밀도 판정 확인용** — 두 PDF가 `chars` 기준(페이지당 300자)의 양쪽에 놓여 있다.
  `안전-교육-자료.pdf`는 채택, `점검-기록지-스캔.pdf`는 텍스트 추출로 원리적 불가라
  비전 전사를 제안받아야 한다. 후자에서 스킬이 조용히 빈 MD를 만들면 그건 결함이다.
- **표 재구성 확인용** — `.hwpx`의 표가 마크다운 표(`| 설비코드 | ... |`)로 떨어지는지 본다.

## 실습 순서

```text
이 워드 파일 마크다운으로 변환해서 Clippings에 넣어줘
projects/second-brain/samples/설비-점검-절차.docx
```

`.hwpx` · `.pdf`도 같은 방식으로 요청한다. 스킬이 게이트에서 커밋 가능성을 물으면 합성
샘플이므로 예로 답한다.

`raw/`에 원본이 복사되므로 **같은 샘플을 두 번 넣으면 중복으로 중단된다.** 반복 실습할
때는 `raw/doc/`·`raw/hwp/`·`raw/pdf/`의 해당 파일과 `Clippings/`의 산출 MD를 지우고
다시 실행한다. (`raw/`는 append-only지만 실습으로 들어간 합성 샘플 정리는 예외로 둔다 —
실제 원문이 들어간 뒤에는 지우지 않는다.)

## 레거시 `.doc` 샘플이 없는 이유

`.doc`(Word 97-2003 바이너리)는 생성에 Word 또는 LibreOffice가 필요해 이 저장소에서
합성하지 못했다. `.doc` 경로(D2a/D2b/D2c)를 실습해야 하면 아래로 만든다.

- **Windows** — `설비-점검-절차.docx`를 Word로 열고 `다른 이름으로 저장` → 파일 형식
  `Word 97-2003 문서 (*.doc)`. 이 파일로 D2c(Word COM) 경로를 검증할 수 있다.
- **macOS** — LibreOffice 설치 후:
  ```bash
  soffice --headless --convert-to doc 설비-점검-절차.docx
  ```

`.doc` 경로는 **Windows 실기기에서 아직 미검증**이다(`doc2md-ingest/SKILL.md` § 근거·주의).
컨설팅 환경이 Windows라면 이 샘플로 검증하고 결과를 스킬 문서에 기록한다.

## 재생성

생성 스크립트는 이 저장소에 커밋하지 않았다. 샘플을 바꿔야 하면 `python-docx`(docx),
`python-hwpx`(hwpx), Pillow + headless Chrome(PDF)으로 다시 만든다.
